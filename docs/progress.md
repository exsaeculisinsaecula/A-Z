## 검토 결과 요약 (계획 단계)

| # | 발견 | 조치 |
|---|---|---|
| 1 | 처음 쓴 문서가 Python판이었음 | 모든 문서를 Flutter·보관함 기준으로 다시 씀 |
| 2 | 처음 안이 특정 아카이브(Z:) 중심이었음 | 아무 드라이브·위치에 새 폴더로 시작(D-05) |
| 3 | 사본 방식이라 용량이 늘어남 | 가져오기 전 용량·남은 공간 미리 보기, 모자라면 막음 |
| 4 | 보관함이 드라이브·기기마다 다른 곳에 있음 | 최근 보관함 목록은 기기별 설정에(VaultCatalog) |
| 5 | 아무 위치나 고르면 위험한 곳도 고를 수 있음 | LocationCheck 규칙(시스템 폴더·중첩·공간·권한) |
| 6 | Android 저장소 접근 제한 | 사이드로드 전제로 「모든 파일 접근」, 헤드셋은 adb appops |
| 7 | 폰·헤드셋 화면과 입력 | 반응형 1·2·3단, hover 없이 모든 기능, 터치 48dp |
| 8 | 3D 궤도 뷰가 가장 큰 위험 | 피드 먼저(M2), 궤도 뷰는 M3, 자동 품질 조절 |
| 9 | 에뮬레이터에 arm64 APK가 안 깔림 | e2e는 debug 빌드, release는 실기기 |
