## 1. 소개

### 1.1 목적

A-Z가 **무엇을 해야 하는지**를 정한다. 어떻게 만드는지는 [AZ-AD](design.md)가, 어떤 순서로 만드는지는 [AZ-SDP](tasks.md)가 정한다.

### 1.2 범위

사진·영상을 보관함 폴더 하나에 모아 피드와 3D 궤도로 보여주는 로컬 앱.

- **하는 것**: 보관함 만들기·열기, 포스트 작성·수정·삭제, 가져오기, 피드·궤도 뷰, 검색·필터, 튜토리얼.
- **하지 않는 것**: 클라우드 동기화, 여러 사용자, SNS 업로드, 편집 기능, iOS·macOS, 몰입형 XR, Play 스토어 배포.

### 1.3 제약

| ID | 제약 |
|---|---|
| CN-01 | Flutter(Dart 3) 하나로 Windows + Android |
| CN-02 | 대상: Windows 10/11 x64, Android 10+ arm64, XR 헤드셋은 2D 패널 |
| CN-03 | 네트워크 미사용. release APK에 INTERNET 권한 없음 |
| CN-04 | Android 저장소는 「모든 파일 접근」 (사이드로드 전제) |
| CN-05 | 구조: 스타터형 평면 + 객체지향 |
| CN-06 | 패키지는 design.md 13절 표에 있는 것만 |
| CN-07 | 대상 지역 KR, 로캘 `ko-KR` |

### 1.4 용어 정의

| 용어 | 코드 | 뜻 |
|---|---|---|
| 보관함 | `Vault` | 사용자가 고른 폴더. 기록이 평범한 파일로 들어 있음 |
| 포스트 | `Post` | 기록 1건 = `.md` 파일. 메모 + 첨부 0~4 + 카테고리 + 태그 + 시각 |
| 첨부 | `MediaRef` | 포스트에 붙은 사진·영상. 보관함 기준 상대 경로 |
| 카테고리 | `Category` | 보관함 바로 아래 폴더. 색 하나. 없으면 「미분류」 |
| 태그 | `TagParser` | 메모의 `#단어` |
| 가져오기 | `ImportJob` | 바깥 파일을 **복사**해 보관함에 넣기 |
| 내비게이터 | `NavigatorCard` | 선택 포스트 상세 카드 |
| 휴지통 | `Trash` | `.az/trash/`. 복원 가능 |
| 검증 | verification | 요구대로 만들었는지 확인 |
| 확인 | validation | 사용자에게 맞는지 확인 |

### 1.5 요구 문장 규칙

- 의무 표현: **해야 한다** · **하는 것이 좋다** · **해도 된다** · **할 수 있다**.
- 우선순위: **M** 필수 · **S** 중요 · **C** 선택 (MoSCoW).
- 검증: **T** 시험 · **D** 시연 · **I** 검토 · **A** 분석.
